# Manga Lyric Card Workflow

This guide outlines how to create lyric card visuals with a manga aesthetic while ensuring the same text content appears both inside a speech bubble and as a subtitle along the bottom of the frame. The process works well in CapCut, Canva, or any editor that supports layers.

## 1. Canvas Setup
1. Create a 16:9 canvas (1920×1080).
2. Place the main character illustration (e.g., tall blonde woman, 20 years old, Russian-inspired styling) against an urban neon background.
3. Add lighting overlays (flash streaks, HDR glows) to reinforce the paparazzi/flashback theme.

## 2. Speech Bubble Layer
1. Draw or import a clean white manga speech bubble.
2. Set the speech bubble text using a manga hand-written style font.
3. Break the lyrics into short lines, for example:
   ```
   J'aurais dû mitrailler,
   Ton sourire en rafale,
   Flashs dans la nuit, j’ai raté l’instant fatal.
   ```
4. Double-check spelling, accents, and punctuation before proceeding.

## 3. Subtitle Layer
1. Add a separate text layer at the very bottom of the frame.
2. Use a neutral sans-serif font (Arial or Helvetica), pure white (#FFFFFF), with no shadow or outline.
3. Copy **exactly** the same lines from the speech bubble and paste them in the subtitle layer. Maintain identical line breaks so that both areas display the same content.
4. Center-align the subtitle text and provide generous padding from the bottom edge for readability.

## 4. Styling Tips
- Use semi-transparent dark gradient behind the subtitle only if the background is too bright, but keep the text itself plain.
- Apply subtle motion (scale/position) to the speech bubble if the video needs extra energy; leave the subtitle static for legibility.
- Keep a consistent font size for subtitles across all lyric cards so viewers can read at a glance.

## 5. Export Checklist
- Verify both text areas contain the same lyrics without truncation.
- Confirm the subtitle font renders sharply at 1080p.
- Export each card as a PNG (if building a video later) or compile the timeline directly in your editor.

Following this structure ensures professional-looking lyric visuals where stylized manga typography coexists with clean, simple subtitles.
